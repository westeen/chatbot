# Pixel: Chatbot

## Technologies
- Next.js, TypeScript, Tailwind CSS
- Vercel AI SDK (`ai`)
- LangChain
- OpenAI GPT-4o-mini

## How to run
1. Install the packages:
```bash
   npm install
```
2. Create a file `.env.local` in the project folder and add your key

3. Start the app:
```bash
   npm run dev
```
